# Voice synthesis

GhostIT uses Android `TextToSpeech`; exact timbre depends on the TTS engine installed on the device. Presets control pitch/rate defaults and persona delivery. `COMEDY_CHAOS` is an original caricature, not a celebrity voice clone.

Chat commands: `/voice <PRESET>`, `/tts on`, `/tts off`, `/tts preview`, `/tts stop`, `/speak <text>`.
